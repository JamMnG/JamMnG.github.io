Social Reading (맞춤형 소셜 독서 노트)

사용자의 읽기 취향을 분석하고 기록을 공유하는 데이터 기반 소셜 플랫폼

💡 서비스 주요 기능 및 구현 기술

국내 도서 DB 연동 및 API 최적화

외부 도서 검색 API의 속도 저하를 방지하기 위해 Redis 인메모리 캐싱을 도입했습니다. 빈번한 검색 요청을 캐시에서 즉시 반환하여 캐시 적중률 72%, 평균 응답 속도 128ms를 달성했습니다.

실시간 자동 저장(Auto-save) 시스템

사용자가 독서의 흐름을 놓치지 않도록 '자동 저장됨' 기능을 구현했습니다. 작성 중인 본문과 태그는 백엔드의 Upsert 비동기 통신을 통해 데이터 유실 없이 실시간으로 저장됩니다.

데이터 기반 개인화 추천 (95% 매칭)

사용자의 독서 기록과 선호 태그를 분석하여 다른 사용자의 데이터와 대조합니다. 이를 통해 취향 매칭률(%)을 수치화하고 정밀한 개인 맞춤형 도서를 추천합니다.

관심사 기반 소셜 네트워킹 피드

비슷한 독서 취향을 가진 사용자들의 노트를 실시간 피드로 제공합니다. RDB 정규화 설계를 통해 효율적인 데이터 관리를 수행합니다.

⚙️ 핵심 백엔드 로직 (자동 저장 및 백그라운드 처리)

UI의 '자동 저장' 기능을 지원하고 서버 응답 성능을 방어하기 위해 FastAPI의 BackgroundTasks를 활용한 로직입니다. 


from fastapi import APIRouter, BackgroundTasks, Depends
from pydantic import BaseModel
from services import note_service, recommend_service

router = APIRouter()

class NoteAutoSaveRequest(BaseModel):
    book_title: str
    rating: int
    content: str
    tags: list[str]

@router.put("/api/v1/notes/auto-save")
async def auto_save_note(note_data: NoteAutoSaveRequest, background_tasks: BackgroundTasks):
    """
    실시간 자동 저장을 수행하고, 무거운 분석 작업은 백그라운드에서 처리합니다.
    """
    # 1. Upsert 로직: 기존 노트가 있으면 업데이트, 없으면 생성 (DB 부하 최소화)
    note = await note_service.upsert_note(note_data)
    
    # 2. 백그라운드 작업: 태그 매핑 및 추천 알고리즘 프로필 업데이트
    # 클라이언트에게 즉시 응답을 보내기 위해 메인 스레드에서 분리
    background_tasks.add_task(recommend_service.update_user_taste_profile, note.user_id)
    
    return {"status": "success", "message": "노트가 안전하게 자동 저장되었습니다."}

💡 기술 적용 포인트 (Key Achievements)

🔄 Upsert 기반의 무중단 자동 저장

잦은 자동 저장 요청에도 DB 성능을 유지하기 위해 INSERT ON DUPLICATE KEY UPDATE(Upsert) 방식을 채택하여 DB I/O 부하를 크게 줄였습니다.

⚡ Background Tasks를 활용한 논블로킹 처리

태그 파싱 및 추천 알고리즘 갱신과 같은 무거운 작업은 백그라운드로 위임하여 128ms의 빠른 응답 속도를 유지하도록 설계했습니다.
